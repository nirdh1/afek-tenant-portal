# פורטל הדיירים – מתחם יצחק רבין–אפק

אתר לניהול הקשר עם בעלי הדירות בפרויקט הפינוי-בינוי.

**מה יש באתר**
- **דף הבית (ציבורי):** מצב הפרויקט, התקדמות החתימות, עדכונים ומפגשים קרובים, וטופס בקשת הרשמה.
- **כניסה עם קוד ב-SMS:** רק מספרים שהנציגות הוסיפה מקבלים גישה. מספר לא מוכר נשאר "ממתין לאישור".
- **אזור אישי:** פרטי הדירה (גוש, חלקה, שטח בנסח, שטח מדוד, תמורה), מסמכים (נסח, הסכם, מדידה), סטטוס החתימה, ועדכון פרטים: גר בדירה, מושכרת (כולל פרטי השוכר) או ריקה.
- **לוח הודעות ושאלות:** כנסים, חוזי מכר, התקדמות ההסכם ושאלות לעורכי הדין. דייר בוחר אם ההודעה פומבית או פרטית. עורך דין עונה באופן פומבי או פרטי לשואל בלבד.
- **פאנל ניהול:** טבלת דירות ודיירים, עריכת כל דירה, העלאת נסחים ומסמכים, הוספת משתמשים (דייר, עורך דין, נציגות), אישור ממתינים, מפגשים, מצב הפרויקט ומעקב פעילות של כל המשתמשים.

**אבטחה:** ההרשאות נאכפות במסד הנתונים עצמו (Row Level Security). דייר רואה רק את הדירה, המסמכים וההודעות הפרטיות שלו. עורכי הדין והנציגות רואים הכול, ורק הנציגות יכולה לשנות נתונים.

## התקנה (פעם אחת)

### 1. Supabase (מסד נתונים, כניסה ואחסון קבצים)
1. נרשמים ב-https://supabase.com ויוצרים פרויקט חדש. כדאי לבחור אזור קרוב, למשל Frankfurt.
2. **SQL Editor > New query**: מדביקים את כל התוכן של `supabase/schema.sql` ולוחצים **Run**. אם יש בפרויקט טבלאות ישנות, מריצים במקומו את `supabase/fresh_install.sql`, שמוחק אותן ומתקין מחדש.
3. מוסיפים את עצמכם כמנהלים (מחליפים את המספר, בפורמט 972 בלי האפס):
   ```sql
   insert into invites (phone, full_name, role) values ('972501234567', 'השם שלי', 'admin');
   ```
4. **Authentication > Sign In / Providers > Phone**: מפעילים ובוחרים ספק SMS (למשל Twilio) ומזינים את פרטי החשבון שלו.
5. **Project Settings > API**: מעתיקים את `Project URL` ואת `anon public key`.

### 2. העלאה לאוויר עם Vercel
1. נרשמים ב-https://vercel.com עם חשבון ה-GitHub ומייבאים את המאגר הזה.
2. ב-Environment Variables מוסיפים את שני הערכים מ-Supabase:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
3. לוחצים Deploy. אפשר לחבר דומיין משלכם בהגדרות של Vercel.

### 3. הזנת נתונים
נכנסים לאתר עם הטלפון שלכם. בלשונית **ניהול** מוסיפים דירות, מעלים נסח לכל דירה ומוסיפים את מספרי הטלפון של בעלי הדירות ושל עורכי הדין.

## פיתוח מקומי
```bash
cp .env.example .env.local   # ממלאים את שני הערכים
npm install
npm run dev
```

## מבנה
- `supabase/schema.sql`: טבלאות, הרשאות ופונקציות
- `app/`: הדפים (Next.js)
- `app/actions.js`: כל פעולות השמירה, וכל אחת נרשמת ביומן הפעילות
- `components/`: טפסים ורכיבים
